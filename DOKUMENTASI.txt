FITUR AKTIF (v5.0)
===================================================================

[CEK 1] MATKUL BARU
  - API: core_enrol_get_users_courses
  - Cek apakah matkul sudah ada di Notion (by Name)
  - Simpan ke Notion dengan prefix [MATKUL]
  - Notif Telegram hanya saat ada matkul baru (awal semester)
  - Fitur Tambahan: Notifikasi penambahan matkul baru otomatis dilewati jika terdapat status penanda `[STATUS] Matkul Komplit` di Notion (untuk menghindari spam berkali-kali).

[CEK 2] TUGAS & KUIS
  - API: core_calendar_get_action_events_by_courses
  - Filter timesortfrom = sekarang (tidak ambil event yang sudah lewat)
  - Cek duplikat: Name + Mata Kuliah di Notion
  - Notif Telegram jika ada tugas baru
  - Fitur Tambahan: Pengecekan nama tugas terhadap pola akhir sesi (Sesi 8 atau Aktivitas Belajar 15).

[CEK 3] DISKUSI FORUM
  - API 1: mod_forum_get_forums_by_courses       → Ambil semua forum
  - API 2: mod_forum_get_forum_discussions        → Ambil diskusi per forum
  - API 3: core_completion_get_activities_completion_status → Status selesai
  - Filter: hanya forum yang namanya diawali "diskusi", "kehadiran", atau "tugas"
  - Completion status dibaca dari Activity Completion Moodle (= tanda hijau Done)
  - Completion map dibangun SEKALI per course (efisien, bukan per diskusi)
  - Fallback: mod_forum_get_discussion_posts jika cmid tidak tersedia
  - Fitur Tambahan: Pengecekan nama forum dan nama diskusi terhadap pola akhir sesi (Sesi 8 atau Aktivitas Belajar 15).

  Decision matrix tiap diskusi:
  ┌─────────────────────────────┬──────────────┬──────────────────────────────┐
  │ Kondisi                     │ Di Notion?   │ Aksi                         │
  ├─────────────────────────────┼──────────────┼──────────────────────────────┤
  │ State >= 1 (Done di Moodle) │ Sudah ada    │ Update Notion → "Selesai" ✅ │
  │ State = 0  (Belum)          │ Sudah ada    │ Skip (sudah dinotif)         │
  │ State >= 1 (Done di Moodle) │ Belum ada    │ Simpan langsung sbg Selesai  │
  │ State = 0  (Belum)          │ Belum ada    │ Simpan + Notif Telegram 🔔   │
  └─────────────────────────────┴──────────────┴──────────────────────────────┘

[CEK 4] PESAN DOSEN
  - Deteksi pesan private yang belum dibaca dari dosen di Moodle.
  - Kirim pengingat ke Telegram jika ada unread count > 0 dari orang lain.

[CEK 5 / TELEGRAM KEYWORD] "Matkul Komplit!"
  - API: /getUpdates (Telegram Bot API)
  - Membaca input keyword "Matkul Komplit!" dari TELEGRAM_CHAT_ID yang sah.
  - Jika terdeteksi, bot akan menyimpan penanda status `[STATUS] Matkul Komplit` ke database Notion dan mengirimkan pesan konfirmasi sukses.

[PENANGANAN AKHIR SEMESTER & SESI AKHIR]
  - Jika daftar mata kuliah di e-learning Moodle kosong (semester berakhir):
    1. Bot akan otomatis menghapus status `[STATUS] Matkul Komplit` di Notion (agar siap untuk semester baru).
    2. Bot langsung tidur (return) tanpa mengirimkan laporan periodik.
  - Jika bot mendeteksi pola akhir sesi (Sesi 8 atau Aktivitas Belajar 15) pada run tersebut:
    - Jika semua tugas/diskusi di database Notion sudah selesai ("Selesai") dan tidak ada data terbaru yang ditarik (adaMatkulBaru/adaTugasBaru/adaDiskusiBaru/adaPesanBaru bernilai false), maka bot akan **melewati** pengiriman laporan periodik.

[LAPORAN] PERIODIK (kondisional)
  - Query Notion: semua item dengan Name starts_with "[DISKUSI]" dan tugas calendar.
  - Filter di Java: hanya yang Status bukan "Selesai"
  - Kirim ringkasan ke Telegram berisi daftar tugas & diskusi yang masih belum dikerjakan sebagai pengingat rutin.
  - Dilewati jika kriteria [SESI AKHIR] di atas terpenuhi.

===================================================================
ANTI-DUPLIKASI (State Management)
===================================================================

Karena GitHub Actions bersifat ephemeral (file hilang setiap run),
state disimpan permanen di Notion database.

Method cek di NotionService:
  sudahAda(nama)              → filter: Name == nama
                                Dipakai untuk [MATKUL] (nama sudah unik global)

  sudahAda(nama, namaMatkul)  → filter: Name == nama AND Mata Kuliah == namaMatkul
                                Dipakai untuk [DISKUSI] dan tugas agar
                                "Diskusi.1" dari matkul berbeda tidak
                                saling di-skip satu sama lain

API MOODLE YANG DIGUNAKAN
===================================================================

1. TOKEN / LOGIN
   GET /login/token.php
       ?username={NIM}&password={PASS}&service=moodle_mobile_app
   Response: { "token": "xxx" }

2. SITE INFO / USER ID
   GET /webservice/rest/server.php
       ?wsfunction=core_webservice_get_site_info&wstoken={TOKEN}&moodlewsrestformat=json
   Response: { "userid": 12345, ... }

3. DAFTAR MATKUL
   GET /webservice/rest/server.php
       ?wsfunction=core_enrol_get_users_courses&userid={ID}&wstoken={TOKEN}&moodlewsrestformat=json
   Response: [ { "id": courseId, "fullname": "Nama Matkul", ... } ]

4. CALENDAR EVENTS (tugas/kuis)
   GET /webservice/rest/server.php
       ?wsfunction=core_calendar_get_action_events_by_courses
       &timesortfrom={UNIX_TIMESTAMP}
       &courseids[0]={ID}&courseids[1]={ID}...
   Response: { "events": [ { "name": "Tugas 1", "course": { "id": ... } } ] }

5. FORUM LIST
   GET /webservice/rest/server.php
       ?wsfunction=mod_forum_get_forums_by_courses
       &courseids[0]={ID}&courseids[1]={ID}...
   Response: [ { "id": forumId, "cmid": courseModuleId, "course": courseId, "name": "..." } ]
   NOTE: "cmid" = Course Module ID, unik per aktivitas, kunci untuk completion lookup

6. DISKUSI PER FORUM
   GET /webservice/rest/server.php
       ?wsfunction=mod_forum_get_forum_discussions&forumid={ID}&wstoken={TOKEN}&moodlewsrestformat=json
   Response: { "discussions": [ { "id": discussionId, "name": "Diskusi.1" } ] }

7. ACTIVITY COMPLETION STATUS ← KUNCI DETEKSI "SUDAH DIKERJAKAN"
   GET /webservice/rest/server.php
       ?wsfunction=core_completion_get_activities_completion_status
       &courseid={ID}&userid={USER_ID}&wstoken={TOKEN}&moodlewsrestformat=json
   Response: { "statuses": [ { "cmid": 123, "state": 1, ... } ] }
   State values:
     0 = Belum selesai
     1 = Selesai (complete)
     2 = Selesai dengan nilai lulus (complete pass)
     3 = Selesai dengan nilai gagal (complete fail)
   NOTE: Ini adalah sumber yang SAMA dengan tanda hijau "✓ Done" di UI Moodle

8. POST DISKUSI (fallback)
   GET /webservice/rest/server.php
       ?wsfunction=mod_forum_get_discussion_posts&discussionid={ID}&wstoken={TOKEN}&moodlewsrestformat=json
   Response: { "posts": [ { "userid": 12345, "message": "..." } ] }

API NOTION YANG DIGUNAKAN
===================================================================

1. QUERY DATABASE (cek duplikasi & ambil pending)
   POST https://api.notion.com/v1/databases/{database_id}/query
   Headers: Authorization, Content-Type, Notion-Version: 2022-06-28
   Body: { "filter": { ... } }

2. BUAT HALAMAN BARU
   POST https://api.notion.com/v1/pages
   Body: { "parent": { "database_id": "..." }, "properties": { "Name": {...}, "Mata Kuliah": {...} } }
   Response includes: { "id": "page_id" }  ← disimpan untuk update status

3. UPDATE HALAMAN (tandai Selesai)
   PATCH https://api.notion.com/v1/pages/{page_id}
   Body: { "properties": { "Status": { "status": { "name": "Selesai" } } } }
   NOTE: Gunakan property type "status", bukan "select"

===================================================================
STRUKTUR DATABASE NOTION
===================================================================

Property yang diperlukan:
  Name       | Title  | Nama entri (dengan prefix)
  Mata Kuliah| Select | Nama mata kuliah
  Status     | Status | Status pengerjaan

Nilai Status yang dipakai:
  "Belum dimulai"  → Default saat entry baru dibuat
  "Selesai"        → Di-update otomatis bot saat activity completion state >= 1

Format prefix Name:
  [MATKUL] Nama Matkul       → Mata kuliah aktif
  [DISKUSI] Diskusi.1        → Diskusi forum
  [DISKUSI] Kehadiran Sesi ke-1  → Forum kehadiran
  Nama Tugas / Event         → Tugas dari calendar (tanpa prefix)

===================================================================
CATATAN PENTING & GOTCHA
===================================================================

1. FILE .env HARUS ADA DI .gitignore
   Pastikan baris ".env" ada di .gitignore. Jika tidak, kredensial
   bisa bocor ke GitHub history.

2. PROPERTY STATUS DI NOTION HARUS TIPE "STATUS"
   Bukan "Select". Jika pakai Select, PATCH request untuk update
   status akan gagal karena format JSON berbeda.
   - Status property: { "status": { "name": "Selesai" } }
   - Select property: { "select": { "name": "Selesai" } }

3. COMPLETION API MEMBUTUHKAN USER ID
   core_completion_get_activities_completion_status memerlukan
   userid parameter, bukan hanya token. Pastikan getUserId() berhasil.

4. FORUM CMID MUNGKIN TIDAK ADA
   Jika mod_forum_get_forums_by_courses tidak mengembalikan field "cmid",
   bot otomatis fallback ke cek via mod_forum_get_discussion_posts.
   Cek log "completion state" di GitHub Actions output untuk debug.

5. NOTION TOKEN EXPIRED
   Jika Notion error 401, generate ulang token di notion.so/my-integrations
   dan update GitHub Secret NOTION_TOKEN.

6. DUPLIKASI NOTIF TELEGRAM DARI MASA LALU
   Jika ada entry di Notion dari sebelum perubahan ini, dan entry tersebut
   tidak punya prefix [DISKUSI], maka diskusi dengan nama yang sama akan
   dianggap baru dan dinotif lagi. Solve: hapus atau beri prefix manual.
