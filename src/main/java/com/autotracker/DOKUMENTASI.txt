===================================================================
FITUR SAAT INI
===================================================================

1. [CEK 1] Matkul Baru
   - Deteksi mata kuliah baru yang aktif di e-learning
   - Simpan ke Notion dengan prefix [MATKUL]
   - Notif Telegram hanya sekali di awal semester

2. [CEK 2] Tugas & Kuis
   - Gunakan API: core_calendar_get_action_events_by_courses
   - Parameter timesortfrom = sekarang (tidak ambil event lama)
   - Cek duplikat per Name + Mata Kuliah di Notion
   - Notif Telegram jika ada tugas baru

3. [CEK 3] Diskusi Forum
   - Ambil semua forum via: mod_forum_get_forums_by_courses
   - Filter hanya forum relevan: dimulai dengan "diskusi", "kehadiran", "tugas"
   - Cek partisipasi user via: mod_forum_get_discussion_posts
   - Simpan ke Notion dengan prefix [DISKUSI]
   - Cek duplikat per Name + Mata Kuliah (bukan Name saja)
   - Update status Notion ke "Selesai" otomatis jika user sudah berpartisipasi
   - Notif Telegram jika ada diskusi baru yang belum dikerjakan

4. [LAPORAN] Periodik (selalu jalan tiap run)
   - Query Notion: semua [DISKUSI] yang statusnya bukan "Selesai"
   - Kirim ringkasan ke Telegram setiap run
   - Format pesan:
       📊 Laporan Bot UT | 2026-04-14
       ⏰ 09:00:00
       ⏳ 3 Diskusi belum dikerjakan:
       • Diskusi.1
          📚 Analisis dan Perancangan Sistem
       • Diskusi.1
          📚 Perilaku Organisasi
       💡 Yuk segera dikerjain sebelum deadline!

===================================================================
LOGIKA ANTI-DUPLIKASI (State Management)
===================================================================

Karena berjalan di GitHub Actions (ephemeral), state disimpan di Notion:

- sudahAda(nama)              → cek Name saja (untuk [MATKUL])
- sudahAda(nama, namaMatkul)  → cek Name + Mata Kuliah (untuk [DISKUSI], tugas)

Decision matrix tiap diskusi saat bot run:
+---------------------------+--------------------+---------------------------+
| Kondisi                   | Di Notion?         | Aksi                      |
+---------------------------+--------------------+---------------------------+
| Sudah dikerjakan          | Sudah ada          | Update Notion → Selesai   |
| Belum dikerjakan          | Sudah ada          | Skip                      |
| Sudah dikerjakan          | Belum ada          | Simpan sebagai Selesai    |
| Belum dikerjakan          | Belum ada          | Simpan + Notif Telegram   |
+---------------------------+--------------------+---------------------------+

===================================================================
API MOODLE YANG DIGUNAKAN
===================================================================

1. Login / Token:
   GET /login/token.php?username=NIM&password=PASS&service=moodle_mobile_app

2. Site Info / User ID:
   GET /webservice/rest/server.php?wsfunction=core_webservice_get_site_info

3. Daftar Matkul:
   GET /webservice/rest/server.php?wsfunction=core_enrol_get_users_courses&userid=X

4. Calendar Events (Tugas/Kuis):
   GET /webservice/rest/server.php?wsfunction=core_calendar_get_action_events_by_courses
       &timesortfrom=UNIX_TIMESTAMP
       &courseids[0]=X&courseids[1]=Y...

5. Daftar Forum:
   GET /webservice/rest/server.php?wsfunction=mod_forum_get_forums_by_courses
       &courseids[0]=X...

6. Diskusi per Forum:
   GET /webservice/rest/server.php?wsfunction=mod_forum_get_forum_discussions&forumid=X

7. Cek Partisipasi User:
   GET /webservice/rest/server.php?wsfunction=mod_forum_get_discussion_posts&discussionid=X

===================================================================
API NOTION YANG DIGUNAKAN
===================================================================

1. Query database:
   POST /v1/databases/{database_id}/query

2. Buat halaman baru:
   POST /v1/pages

3. Update halaman (tandai Selesai):
   PATCH /v1/pages/{page_id}
   Body: { "properties": { "Status": { "status": { "name": "Selesai" } } } }

===================================================================
ENVIRONMENT VARIABLES (.env / GitHub Secrets)
===================================================================

UT_NIM              → Nomor Induk Mahasiswa
UT_PASS             → Password e-learning UT
TELEGRAM_BOT_TOKEN  → Token bot Telegram
TELEGRAM_CHAT_ID    → Chat ID tujuan notif
NOTION_TOKEN        → Notion Integration Token
NOTION_DATABASE_ID  → ID database Notion

===================================================================
CATATAN PENTING
===================================================================

1. File .env HARUS ada di .gitignore — jangan pernah push ke GitHub!
2. Gunakan GitHub Secrets untuk variabel saat run di GitHub Actions
3. Notion "Status" property harus bertipe "status" (bukan "select")
   dan harus ada opsi bernama "Selesai"
4. Token Notion yang expired/revoked akan menyebabkan semua query gagal
